# StepUp — Unified Journey Update

هذا التحديث يحول تجربة الطالبة إلى رحلة واحدة داخل StepUp مع الحفاظ على Firebase والفصول والتقارير والمساعد والقاموس.

## الملفات التي يتم استبدالها
- `app.js`
- `index.html`

## الملفات الجديدة
- `journey-engine.js`
- `journey.css`

## رحلة الطالبة
Home → My Journey → My Progress → Assistant

داخل كل وحدة:
Master the Unit → Read → Listen → STEP Practice → Final Challenge

- Master the Unit يحتوي 4 مهام تكيفية صغيرة.
- الدعم يظهر فقط عند الحاجة.
- Dictionary + My Words يبقيان أدوات سريعة.
- Writing Coach اختياري.
- STEP Practice لا يحجب استمرار الرحلة.
- نتائج الرحلة تحفظ في attempts الحالية، لذلك تستفيد منها تقارير المعلمة الحالية.

## النطاق
Units 1–6، مع 291 سؤالًا في محرك الرحلة.
